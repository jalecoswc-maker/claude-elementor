# Estrutura do site

## Páginas
1. Home (mesmo roteiro da home do Chaveiro Central, adaptado)
2. **Psicanalista em Indaiatuba** (página própria; usa as 17 palavras de "Prioridade principal")
3. Sobre
4. Serviços (página-índice)
5. Atendimento (presencial no Instituto Laar, online, horários, mapa)
6. Blog (template de listagem e de artigo)
7. FAQ
8. Contato

Regra: **bloco de FAQ no final de cada página**, com perguntas diferentes por página (confirmar com o usuário se queria também uma página FAQ separada; a lista de páginas inclui "faq").

## Mega menu "Serviços" (7 colunas)
| Coluna | Conteúdo |
|---|---|
| Trauma e tanatologia (especialização) | trauma, finitude, morte e sentido de vida |
| Ansiedade e sobrecarga | grupo "Ansiedade, estresse e sobrecarga" |
| Autoestima e autoconhecimento | grupo homônimo |
| Relacionamentos | grupo homônimo |
| Luto, tristeza e mudanças | grupo homônimo (inclui Acompanhamento para luto) |
| Trabalho e desenvolvimento emocional | grupo homônimo |
| Modalidades | presencial, online, adultos |

Decisão de SEO: **não criar uma página por palavra-chave** (80+ páginas curtas = conteúdo raso).
Criar **7 páginas de categoria**, cada uma com uma seção (H2) por palavra-chave; o mega menu aponta para a seção por âncora.
Verificar se o PRO Elements tem widget de mega menu; se não, usar menu suspenso em colunas.
